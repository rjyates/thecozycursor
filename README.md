# The Cozy Cursor: website

Public static site for The Cozy Cursor, served free by GitHub Pages. It is the brand hub: home page, shop page (linking to the Fourthwall shop once it opens), privacy policy and affiliate disclosure.

- **Live:** https://rjyates.github.io/thecozycursor/
- **Pinterest:** https://www.pinterest.com/thecozycursor/

Plain HTML and CSS, with no build step, trackers or third-party requests.

**Editing:** change the `.html` files and push to `main`. GitHub Pages republishes within a minute or two.
